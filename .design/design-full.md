# 舟舟与小羊 · 完整设计文档

> 版本 v2.0 · 合并自 design-requirements.md & design.md · 2025年5月

## 一、项目概述

「舟舟与小羊」是一个为两人专属打造的纪念网站，以 520 为首发节点。网站定位为**私密、沉浸、温柔**的二人世界档案库，后续演进为微信小程序与安卓 APP。

---

## 二、全局视觉风格

### 2.1 主题：清新极光风（Aurora Fresh）

摒弃传统沉重的深色模式，采用明亮、通透、富有生命感的极光配色体系。

**核心 Prompt（可在其他 AI 工具中复用）：**

> "请帮我使用 Tailwind CSS 设定一个网页的全局样式。要求摒弃传统的沉重深色模式，改用『清新极光风』。背景使用动态的线性渐变（linear-gradient），颜色交织薄荷绿（#d1fae5）、淡紫（#f3e8ff）和浅蓝（#e0f2fe），并带有缓慢的呼吸动画（15s 周期）。字体采用高级的混合排版：中文使用 Noto Serif SC（思源宋体），英文字母和数字使用电影感的罗马衬线体 Cinzel 和细体 Montserrat。强调色定义为：高级薄荷绿（#10B981）和浪漫紫（#8B5CF6）。"

### 2.2 背景

- 动态线性渐变，颜色交织薄荷绿 `#d1fae5`、淡紫 `#f3e8ff`、浅蓝 `#e0f2fe`
- 带有缓慢呼吸动画，周期 15s，营造极光流动感
- 动画使用 CSS `@keyframes`，时长变量统一管理

### 2.3 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主强调色 | `#10B981` | 高级薄荷绿，用于高亮、图标、激活态 |
| 副强调色 | `#8B5CF6` | 浪漫紫，用于标签、悬浮按钮、特殊节点 |
| 毛玻璃背景 | `rgba(255,255,255,0.4)` | 导航栏、卡片、弹窗通用 |
| 文字主色 | `#1f2937` | 正文标题 |
| 文字辅色 | `#6b7280` | 说明文字、标签 |

所有颜色值必须在 `:root` 中以 CSS 变量定义，组件内只引用变量，禁止硬编码。

### 2.4 排版

| 用途 | 字体 | 说明 |
|------|------|------|
| 中文正文 | Noto Serif SC（思源宋体） | 温润感，适合情感内容 |
| 英文 / 数字标题 | Cinzel | 电影感罗马衬线体 |
| 英文细体辅助 | Montserrat Light | 标签、说明文字 |
| 数字计数器 | 任意字体 + `tabular-nums` | 防止数字跳动 |

## 三、全局组件规范

### 3.1 胶囊型导航栏

- 固定在页面顶部，采用毛玻璃质感
- 背景 `rgba(255,255,255,0.4)`，高斯模糊 16px，极细白色边框
- 包含四个普通链接（灰蓝色，Hover 时变为薄荷绿 `#10B981`）
- 最右侧一个高亮按钮，白色背景 + 右箭头图标，点击缩放反馈 `active:scale-95`
- 移动端适配：链接收起为汉堡菜单，保留高亮按钮常驻

**核心 Prompt：**

> "请实现一个固定在页面顶部的『胶囊型导航栏』。风格采用通透的亮色毛玻璃质感（Glassmorphism），背景为 rgba(255,255,255,0.4)，带有 16px 的高斯模糊和极细的白色边框。导航包含四个普通链接（颜色为灰蓝，Hover 时变为薄荷绿），以及最右侧一个带有白色背景和右箭头的『高亮按钮』，具有点击缩放反馈（active:scale-95）。"

### 3.2 悬浮音乐播放器

- 位于页面右下角，默认显示为唱片机图标触发器
- 点击后向上弹出毛玻璃歌单面板，包含：
  - 歌单列表（标题 + 时长）
  - 当前播放歌曲状态栏（歌名 + 跳动音轨动效）
  - 主控播放 / 暂停按钮
- 正在播放的歌曲高亮显示（薄荷绿加粗 + 音轨跳动图标）
- 支持顺序自动循环播放

**自动播放规范：** 浏览器默认禁止自动播放，必须在用户首次点击页面任意区域时触发 `audio.play()`，不得使用 `autoplay` 属性。

**进阶体验设计思路：**

将单一播放/暂停升级为「可自选歌曲的播放列表面板」。点击右下角唱片触发器，向上弹出毛玻璃面板，包含歌单列表、当前播放状态栏及主控按钮。JS 中维护 `songs` 数组（含 `title` 和音频 `url`），支持任意切换；监听 `<audio>` 的 `ended` 事件实现自动顺播：`nextIndex = (currentIndex + 1) % songs.length`。

### 3.3 毛玻璃卡片（通用组件）

所有内容卡片统一使用以下样式规格：

```css
背景：rgba(255,255,255,0.4)
模糊：backdrop-filter: blur(16px)
边框：1px solid rgba(255,255,255,0.3)
圆角：16px
内边距：1.5rem
```

### 3.4 防抖动倒计时组件

**核心 Prompt：**

> "请使用 HTML/JS 写一个正计时/倒计时器，要求绝对不能出现数字跳动、宽度闪烁的问题。核心方案：为包含数字的 div 设置强制的固定宽度（如 w-20 md:w-32），并在 CSS 中启用 font-variant-numeric: tabular-nums。视觉上，数字要超大（text-8xl）、极细（font-light），底部的文字标签具有超大字间距（tracking-[0.5em]），整体浮于带有深色渐变遮罩的背景图之上。"

具体要求：

- 显示两人在一起的天数（正计时）或特殊节日倒计时
- 数字超大字号（≥ 6rem），极细字重（font-weight: 300）
- 数字下方标签具有超大字间距（letter-spacing: 0.5em）
- 数字显示区域设置固定宽度 + `tabular-nums`，绝对禁止跳动闪烁
- 浮于带有深色渐变遮罩的背景图之上

## 四、页面模块详细需求

### 4.1 首页（index）

#### 倒计时 / 正计时组件

见 3.4 节规范。

#### 生活碎片相册

- 瀑布流布局展示两人合照
- 照片悬浮时轻微上浮 + 毛玻璃遮罩显示拍摄日期和简短文字
- 支持点击放大查看（全屏 Lightbox）

---

### 4.2 小餐馆（/restaurant）

**定位：** 两人专属的「人间烟火气」档案库。

#### 功能一：美食探店日记

- 瀑布流布局展示菜品照片
- 每条记录包含：菜品照片、餐厅名称、就餐日期、地点标签、两人各自评分（1–5 星）、真实评价文字
- 支持按城市 / 评分筛选
- 顶部展示探店总数统计

#### 功能二：私房菜谱库

- 卡片式布局，每张卡片展示菜品封面图 + 菜名 + 难度标签
- 点击进入详情页，包含：
  - 食材清单（数量、单位）
  - 分步骤图文教程
  - 「翻车小贴士」和「成功秘诀」两个特殊文本块（使用暖色 / 冷色区分）
  - 是否为小羊手作标签

---

### 4.3 小酒馆（/tavern）

**定位：** 微醺时刻与夜间谈心角。

#### 功能一：微醺图鉴

- 网格布局展示探店酒吧 / 惊艳酒款记录
- 每条记录包含：场所照片、名称、地址、酒款亮点、氛围评价、再访意愿（是 / 否）

#### 功能二：调酒配方字典

- 顶部搜索框 + 基酒分类筛选（伏特加 / 金酒 / 朗姆 / 威士忌 / 其他）
- 每条配方包含：特调名称、基酒、辅料配比、调制步骤、口味标签（甜 / 酸 / 烈 / 清爽）
- 支持模糊搜索特调名称或原料名

---

### 4.4 小诊所（/clinic）

**定位：** 最贴心的健康守护站，此模块为核心功能，设计需体现温柔与私密感。

#### 功能一：生理期跟踪仪

- 日历视图（月份维度）+ 周期统计条形图
- 特殊日子（预测经期开始前 3 天）触发全页面「暖心模式」：背景渐变变暖、顶部出现温柔提示横幅
- 记录项包含：开始日期、持续天数、痛感等级（1–5）、症状标签
- 自动预测下次经期（云端算法，前端仅展示结果）

#### 功能二：女性好物备忘录

- 静态信息页，记录卫生巾品牌、型号、尺寸、购买渠道、过敏史备注
- 设计为便签 / 卡片风格，温柔粉色调

#### 功能三：健康小百科

- 手风琴（Accordion）展开式布局
- 分类：妇科疾病预防 / 日常保养 / 营养补充
- 内容以图文结合形式呈现，配温柔插画图标

#### 功能四：用药记录与提醒

- 日历标注服药日期（已服 / 未服 / 漏服 三种状态）
- 新增用药时填写：药品名称、剂量、服药时间、疗程天数
- 疗程期间每天显示「今日提醒」悬浮条

---

### 4.5 纪念博物馆（/museum）

**定位：** 动态生长的爱情编年史。

#### 核心功能：发光时光轴

- 纵向居中的发光时间轴（薄荷绿 / 紫色双色光晕）贯穿页面
- 节点类型及视觉差异：

| 节点类型 | 图标 | 颜色 |
|---------|------|------|
| 告白 / 重要情感节点 | 心形 | 浪漫紫 |
| 礼物 | 礼物盒 | 薄荷绿 |
| 演唱会 / 活动 | 票根 | 琥珀色 |
| 旅行 | 地图标记 | 蓝色 |

- 每个节点点击后展开详情卡片：日期、标题、故事描述、照片（最多 4 张）
- 旅行节点联动地图展示（高德地图 / Leaflet）
- 页面滚动时节点依次入场动画（GSAP ScrollTrigger）

## 五、隐秘创作者模式（In-App Editing）

### 5.1 触发方式

以下任一操作触发解锁密码框：

- 长按顶部 Logo 持续 3 秒
- 快速点击底部红心图标 3 次（间隔 < 500ms）

密码框样式：毛玻璃风格全屏遮罩 + 居中输入框，输入错误时轻微抖动动效。

**设计理念：** 不必为了发布一张照片特意登录死板的后台网页，将「后台功能」直接融入前端日常页面。普通访客看只是一个展示页；输入专属暗号后，页面解锁进入「编辑模式」，时光轴旁自动多出 **+ 添加纪念日** 按钮，食谱页多出 **+ 上传新菜** 按钮。体验极度顺滑，不会打破浪漫氛围。

### 5.2 解锁后能力

解锁状态仅在当前会话（SessionStorage）中保持，关闭标签页后失效。

| 模块 | 新增编辑能力 |
|------|------------|
| 所有页面 | 顶部出现半透明「编辑模式」提示条 |
| 小餐馆 | 卡片右上角出现「＋新增探店」「✎ 编辑」按钮 |
| 小酒馆 | 「＋添加配方」「＋记录探店」按钮 |
| 小诊所 | 「＋记录本次经期」「＋添加用药」按钮 |
| 纪念博物馆 | 时光轴上出现「＋添加新节点」按钮 |

### 5.3 上传弹窗规范

- 弹窗样式：毛玻璃卡片，居中显示，背景半透明遮罩
- 图片上传区：虚线边框拖拽区 + 点击选择，支持预览
- 表单字段根据模块定制，简洁不超过 6 个字段
- 「保存」按钮颜色为薄荷绿主色，「取消」为次要按钮
- 保存成功后动画消失，页面无刷新更新数据

## 六、响应式与多端适配

| 断点 | 宽度 | 布局变化 |
|------|------|---------|
| 移动端 | < 768px | 单列布局，导航收起为汉堡菜单，字号缩小 |
| 平板 | 768px – 1024px | 双列卡片布局，侧边栏折叠 |
| 桌面 | > 1024px | 三列卡片 / 时光轴居中宽布局 |

采用移动端优先（Mobile First）策略，基础样式为移动端，通过 `min-width` 断点逐步增强。

## 七、动效规范

| 动效类型 | 参数 | 适用范围 |
|---------|------|---------|
| 页面入场 | GSAP fadeInUp，duration 0.6s，stagger 0.1s | 所有页面首屏 |
| 滚动触发 | GSAP ScrollTrigger，start: "top 80%" | 时光轴节点、卡片列表 |
| 按钮 Hover | transform scale(1.03)，150ms ease | 所有可点击卡片 |
| 按钮 Active | scale(0.97)，80ms | 所有按钮 |
| 弹窗出现 | scale(0.95) → scale(1) + opacity，200ms | 上传弹窗、详情卡片 |
| 极光背景 | linear-gradient 位置动画，15s ease-in-out infinite | 全局背景 |

## 八、音频规范

### 8.1 格式选择策略

| 格式 | 推荐度 | 说明 |
|------|--------|------|
| `.mp3` | ★★★ 最推荐 | 压缩率高，兼容性 100%，首选 BGM 格式 |
| `.m4a / .aac` | ★★★ 推荐 | 苹果主推，同体积音质优于 MP3，移动端支持好 |
| `.ogg` | ★★☆ 可用 | 开源免费，音质优秀，但旧版 iOS / Safari 兼容性略差 |
| `.wav` | ✗ 严禁 | 无损但未压缩，单首歌可达数十 MB，严重拖慢加载速度 |

**最佳实践（格式回退机制）：**

```html
<audio id="bgm" loop>
    <source src="music/our-song.mp3" type="audio/mpeg">
    <source src="music/our-song.ogg" type="audio/ogg">
    <source src="music/our-song.m4a" type="audio/mp4">
</audio>
```

### 8.2 自动播放规范

浏览器默认禁止自动播放，必须由用户首次交互触发：

- 禁止使用 `autoplay` 属性及任何违背浏览器规范的黑科技
- 在 UI 层面设计自然的「交互开关」（如悬浮唱片机图标）
- 当用户产生首次有效点击时（如点击「开启告白」按钮），通过 `click` 事件顺势调用 `audio.play()`
- 这样既符合浏览器规范，又能营造「点击触发惊喜」的仪式感

### 8.3 音量与控制

- 音量默认 50%，提供静音切换
- BGM 格式：优先 `.mp3`，备选 `.m4a`，通过 `<source>` 多格式回退

## 十、全栈架构规划与多端演进（小程序 / APP）

### 10.1 前端跨端框架选型

强烈推荐 **Uni-app + Vue 3**：

- 一套代码同时打包为：微信小程序、安卓 APP（.apk）、H5 网页版
- 完美支持 Tailwind CSS 极光风样式
- 打包为小程序 / APP 后可直接调用手机相册、摄像头、地理定位

### 10.2 数据与后端选型：Serverless（云开发）

推荐 **uniCloud** 或 **微信云开发**：

- 无需购买服务器，框架自带云数据库
- 前台编辑模式直接调用 `uniCloud.database().collection('museum').add({...})`
- 照片自动上传到云存储，数据直接入库

### 10.3 开发 Roadmap

| 阶段 | 目标 | 说明 |
|------|------|------|
| 当前（520 首发） | 纯静态 HTML | 将首屏照片和倒计时写死，部署在 GitHub Pages 作为 520 惊喜 |
| 架构重构期 | Uni-app 项目 | 下载 HBuilderX，转为 Uni-app，打通多页面路由 |
| 「暗号模式」开发 | 云数据库 + 前台上传 | 开通云数据库，开发暗号解锁逻辑与上传弹窗 |
| 功能填充期 | 各模块完善 | 逐个开发生理期记录、调酒配方查询等功能 |
| 最终形态 | 小程序 + APP | 打包微信小程序及安卓 APP，作为终极纪念版 |
